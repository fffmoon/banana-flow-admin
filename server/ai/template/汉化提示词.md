## task
请将example区域的python代码i18n化。将新增的内容，添加到i18n的json文件中。

## rule
1.  i18n工具调用方式为：`from app.core.i18n import i18n; i18n.t("your.key.here")`
2.  翻译键名 (key) 的命名逻辑为：`[模块名].[成功/失败].[字符串含义]`，全部使用小写和点号分隔。例如：
```
  "auth": {
    "success": {
      "login": "登录成功",
      "logout": "退出登录成功",
      "get_info": "获取用户信息成功",
      "register": "注册成功",
      "get_perm_menu": "获取权限菜单成功",
      "get_version": "获取版本号成功"
    },
    "error": {
      "invalid_credentials": "用户名或密码错误",
      "user_frozen": "用户已被冻结",
      "username_taken": "该用户名已被注册"
    }
  },
```
